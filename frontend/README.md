# Intra AI frontend

This Next.js application provides the public jobs flow, candidate portal, Agora interview room, Taylor practice experience, and recruiter workspace.

Use the repository [README](../README.md) for the current architecture, configuration, local startup, security notes, and validation commands.

```bash
cp .env.example .env.local
npm ci
npm run dev
```

The development server is available at `http://localhost:3000` by default.
